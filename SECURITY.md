# Security policy

This repository contains profile documentation only. It has no runtime code.

For vulnerabilities in a project, use the private advisory form on that repository:

- [ctxpack](https://github.com/KodYazicam/ctxpack/security/advisories/new)
- [envsentinel](https://github.com/KodYazicam/envsentinel/security/advisories/new)
- [svgforge](https://github.com/KodYazicam/svgforge/security/advisories/new)
- [hookyard](https://github.com/KodYazicam/hookyard/security/advisories/new)
- [sparkcord](https://github.com/KodYazicam/sparkcord/security/advisories/new)

Please do not open a public issue for a vulnerability. Include the affected version, a minimal reproduction, and the impact. I aim to acknowledge reports within 72 hours.
