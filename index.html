Flagship tools

Four Apache-2.0 tools. Three are on npm; hookyard installs from source.

npm · TypeScript

ctxpack

Packs a repository into an LLM-ready prompt. Respects .gitignore, budgets tokens, redacts secrets. Ships an MCP server.

npm i -g @kodyazicam/ctxpack
ctxpack . -o prompt.md
npm · TypeScript

envsentinel

Validates .env against a JSON schema, scans for leaked secrets, and generates .env.example plus TypeScript types.

npm i -g @kodyazicam/envsentinel
envsentinel check
npm · TypeScript

svgforge

Generates README banners, cards, and stats as committed SVG files. 32 card types, 22 themes, no render service.

npm i -g @kodyazicam/svgforge
svgforge banner --title hello
Python · source install

hookyard

Inspects, verifies, and replays webhooks locally. GitHub, Stripe, Slack, and Discord signatures; SSRF-safe replay.

git clone https://github.com/KodYazicam/hookyard
cd hookyard && pip install -e .
hookyard --port 4242

Why local-first?

The shortest path between your data and the result is the machine you are already using.

Your code stays yoursNo upload, no account, no telemetry.
Works offlineAir-gapped machines, CI runners, locked-down laptops.
ComposablePlain files in, plain files out. Every tool is scriptable.
Agent-readyMCP lets Claude, Cursor, and other clients call the tools directly.
